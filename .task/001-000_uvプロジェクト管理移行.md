# uvによるプロジェクト管理の導入

## ゴール
本プロジェクトの依存関係および仮想環境管理を `uv` で行うため、 `pyproject.toml` と `uv.lock` を生成し、プロジェクト構成を整備する。

## 主な要件
1. **`pyproject.toml` の作成と依存関係定義**:
   - `uv` のプロジェクト形式（`pyproject.toml`）を初期化し、必要なパッケージ（`Flask`）を追加する。
2. **`uv.lock` の生成**:
   - 依存関係をロックし、再構成可能な開発・実行環境を構築する。
3. **動作検証**:
   - `uv run` 経由でアプリケーションが正常に起動・動作することを確認する。
