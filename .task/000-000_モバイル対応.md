# モバイル（スマホ）ブラウザ対応

## ゴール
PCブラウザ専用となっているタワーディフェンスゲームを、スマートフォン（iOS / Android）のブラウザでも直感的にかつ快適にプレイできるように、レスポンシブレイアウトの最適化およびタッチ操作（Pointer/Touch Events）の適合を行う。

## 主な要件
1. **レスポンシブデザインの強化**:
   - Viewport メタタグの最適化（誤ったズームの防止、viewport-fit=cover）
   - スマホ画面（縦画面・横画面）におけるレイアウト最適化（ボタンのタップ領域拡大、フォントサイズ調整）
   - キーボードショートカット表記のスマホ時における非表示・調整
2. **タッチ操作対応**:
   - Pointer Events / Touch Events の適切なハンドリングによるキャンバス上でのセル選択・タワー配置・プレビュー操作の改善
   - スマホのタップ操作によるWeb Audio APIの有効化（音声再生のアンロック）
3. **互換性と既存機能の維持**:
   - PCでの操作性およびハイスコア送信機能（SHA-256 Dynamic Salt検証含む）に影響を与えないこと
